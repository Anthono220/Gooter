# Sequences
These are essentially animations that can be made within GameMaker and can be placed either in the room editor or by an object in game. They can even call functions contained in scripts at certain points via "Moments". Sprites, objects, and text can be placed in sequences and various aspects about them can be changed in keyframes, including (but not limited to) location, size, and opacity.

Examples of sequences that can be created and used are room transitions, in-game cutscenes, and character animations.
