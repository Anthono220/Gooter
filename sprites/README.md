# Sprites
Sprites essentially make up this game's graphics when it comes to characters, objects, and even the HUD. They can either be applied to an object, placed in the room editor by themselves, or drawn by an object.

All of this game's sprites (except for sprites from third-party extensions) are licensed under Creative Commons 4.0 International.

## Note for contributors
If, for whatever reason, you are contributing sprites for this game, you must use the Epik-216 color palette by Fethur (https://lospec.com/palette-list/epik-216) for consistency's sake. Your work will also be licensed under the same Creative Commons license as well.
